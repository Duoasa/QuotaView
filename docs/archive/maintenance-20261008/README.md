## 文档快照与恢复

[markdown-before.tar.gz](markdown-before.tar.gz)保存清理前 111 份 Markdown（含已有未提交内容），[manifest.json](manifest.json)记录逐文件 SHA256、字节数与行数。归档逐项读取校验通过。

归档路径：`active/` 为当前工作区，`entry/` 为旧根入口，`legacy-entry/HANDOFF.md` 为 0.4.8 过渡入口。完整旧 Handoff、阶段续接文档、规格索引、生产审核稿、Prototype 迭代与 UI 参数均可追溯；其中“当前”“下一步”和旧 PID 仅对原日期有效。

查看单份原文，不覆盖当前文件：

```sh
tar -xOf docs/archive/maintenance-20261008/markdown-before.tar.gz active/HANDOFF.md
```

需要批量恢复时先解压到另一个目录，再按差异选择内容；不直接覆盖仍有未提交修改的工作区。

## 职责与修正

- 根入口直接指向实际开发工作区；旧 0.4.8 和阶段 Handoff 只负责转向。
- Handoff 管当前源码/运行/未完成项；SDD 管目标和状态；版本历史保留公开发布事实；Design QA 只记录限定用户结论。
- 生产规则不再重复早期“尚未实施”的提案；明确手动归档、自动弹出、选中动效互斥、当前设置布局与原生异步关闭缺口。
- Desktop 文档区分通用初始化器默认预算与生产 72/64/128 MiB 配置，帧超时按读取停滞计算。
- 冻结 Demo 保留 3 秒/噪点 65% 最终规则；5 秒、固定正文高度和旧按钮布局等被覆盖参数退出有效约束。冻结资产不变。

历史日志内的旧二进制路径代表当时位置；本次被清理的包不再保证可恢复，源代码/冻结包/正式 ZIP 及最近回退包的保留范围以上述清单为准。
