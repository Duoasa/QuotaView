# 重置 Demo 动效性能检查（2026-11-07，0.9.2 Build 12）

此文为 Build 12 的离屏测量记录。Build 18 已将空卡改为不透明暗色、恢复鼠标倾斜；Build 19 已移除生产 Demo，性能实现保留。当前行为见 [重置规格](../specs/codex-quota-reset.md#build-19-恢复正常接入与共享卡片2026-11-07)，下方旧次数/透明度仅为当时测试条件。

用户反馈整段动画有轻微卡顿，同时明确空状态标志应为数学空集符号 ∅。本批保持 Demo，不触达真实额度，不操作实际 UI；检查采用源码审查、运行进程只读采样和原卡面离屏 Metal 基准。

## 实测与边界

Apple M1 Ultra，主屏报告最高 120 Hz。真实卡面资源，623 × 560 像素离屏目标，24,240 个粒子；每次预热 20 帧，统计后续 408 帧。生产 shader 与粒子参数未改变。

| 指标 | 优化前基准 | 复测 |
|---|---:|---:|
| CPU 编码/提交 P95 | 0.018 ms | 0.021 ms |
| GPU 命令 P95 | 0.136 ms | 0.215 ms |
| 离屏提交到完成 P95 | 0.498 ms | 0.718 ms |
| 首次卡面绘制与纹理加载 | 21.24 ms | 19.31 ms |
| 100 次共享资源命中 P95 | 无跨宿主缓存 | 0.00033 ms |

前次首个 shader/pipeline 编译调用约 284.85 ms，发生在主线程资源准备路径；随后同进程编译调用降至 0.08–0.19 ms。复测进程首编译约 1.49 ms，但 Metal 驱动缓存已热，**不能将这一下降归因于本批优化**。本批可确认的改变是编译与纹理上传在后台执行，页面宿主复建复用同一份对象，不重复创建。

GPU 数值有波动，复测并没有证明单帧 shader 变快；两轮均明显低于 120 Hz 的 8.33 ms 帧预算，因此不据此减少粒子或改画质。该离屏测试不包含 WindowServer、玻璃合成、真实 drawable 等待和整个界面布局，不能等同实际动画 FPS 或掉帧率。

3 秒运行进程采样未捕获重置粒子播放，包含其他活动特效与正常 UI 工作，不能用于证明重置卡顿的根因。证据：`.build/reset-performance-092b11-sample.txt`；基准源码、JSON 和定向检查：`.build/reset-performance-092b12/`。

## 已实施

- 原粒子使用 MTKView 固定 60 fps 定时刷新；检测到的主屏支持 120 Hz。改为 macOS 14+ 的视图绑定 CADisplayLink，请求 30–120 Hz、偏好 120 Hz，由系统依据实际所在屏幕及电源条件调度；保持 MTKView 自带定时器暂停，避免双重驱动。尚未测量用户实际屏幕上的呈现 FPS。
- 仅单次消散活跃且可见时创建刷新链；完成、隐藏、离窗、减少动态和卸载时失效。代理弱引用宿主，避免 run loop 强引用造成不可见渲染泄漏。
- 卡面 AppKit 快照仍在主线程首次创建；shader 编译、pipeline 创建和纹理上传移到后台任务。跨宿主共享不可变 GPU 资源与队列，并发请求复用同一个准备任务；等待期间不启动渲染，资源就绪后只在当前仍可播放时启动。
- 保留三帧在途上限、原始 RGBA8 纹理、24,240 粒子、1.7 秒消散、1.15 秒递补触发、0.48 秒回弹与下缘文字避让，未修改 shader 数学或粒子密度。
- 空状态中央图标由托盘修正为数学字符 ∅，保持 45% 不透明度、无扫光和无悬停倾斜；每次重启 Demo 补满 5 张。

## 验证

18 项定向测试通过，覆盖原色粒子、重叠交接、Demo 防重入、并发资源准备合并与缓存复用、离屏宿主刷新链启停/减少动态、原页面飞行动画生命周期。测试与开发包运行结果见 [Handoff](../../HANDOFF.md)。没有主动截图或实际 UI 操作；本批降低了已识别的初始化阻塞与刷新频率不匹配风险，最终流畅度仍需用户体验确认。
