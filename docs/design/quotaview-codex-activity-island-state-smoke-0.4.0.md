# QuotaView 进度条灵动岛规格

> Spec ID：`QV-PRODUCT-ACTIVITY-ISLAND-STATE-SMOKE-006`
>
> 规格状态：`Accepted`
>
> 交付状态：`Verifying`
>
> 更新日期：2026-08-30
>
> 生产基线：`0.3.7 Build 1`
>
> 目标发布版本：`0.4.1 Build 1`

## 决策

保留最初 MetalForge Smoke Progress 的左侧烟雾填充形态，并把前沿位置绑定
到当前 Codex 任务的近似进度。有 `update_plan` 时，QuotaView 只从结构化步骤
状态读取数量：完成步骤计 `1`，进行中步骤计 `0.1`，待处理步骤计 `0`；不
保存步骤文字或计划说明。没有结构化计划时，烟雾使用仅存在本机渲染器内的
生命周期估算：从 `0%` 随活跃时间渐进，并按工具执行、等待确认和上下文整理
设置最低阶段位置；不读取任务文字、模型输出、Token 或工具参数。任务仍在
执行时，计划进度最高为 `95%`、无计划视觉估算最高为 `50%`，只有收到真实
`Stop` 才确认 `100%`。

正常任务启动后先进入 `4 s` 步骤识别窗口，烟雾前沿稳定等待在 `1%`。
识别到有效步骤编排后平滑接入计划近似百分比；识别窗口结束仍无计划时，
从 `1%` 平滑接入无计划单步骤估算，且单步骤计时从窗口结束时开始。迟到的
有效计划仍可接管，任何接管都不得让已经显示的前沿倒退。不得恢复
`15%` 固定偏移。进行中步骤只按单步 `10%` 保守计入，使三步骤和四步骤计划
首次识别时分别约为 `3.3%` 与 `2.5%`，避免刚识别就跳到接近 `20%`。展开态
不直接显示百分比；
有计划时 VoiceOver 朗读同一近似百分比，无计划的视觉估算不伪装成可访问性
精确数值。右侧显示当前状态文字，例如“思考中”或“工作中”。

进度条灵动岛现在是与 AI 球灵动岛并列的顶层样式，不再作为 AI 球的第三种
动画。AI 球样式内部只保留粒子球与波澜光晕两种动画；旧版已经持久化的
`smokeProgress` 会自动迁移为进度条样式，并把 AI 球动画归一为默认粒子球，
不改变用户当前看到的进度条结果。

设置页的灵动岛样式与展开尺寸 Picker 使用原生内容宽度，并让可见的
`NSSegmentedControl` 直接落在设置行的 `18 pt` 右内边距上。不得在 Picker
外套一个更宽且默认居中的透明固定框，否则行布局看似右对齐，但用户实际
看到的分段控件仍会被向左推移。

进度条样式不再为光球预留文字区。展开态改为左右双区：左侧上方显示对话
标题并保留状态圆点，下方显示带流光的当前操作详情；右侧只显示当前状态。
左右区垂直居中，逻辑表面左右内边距均为 `20 pt`，两区之间固定 `14 pt`
间距。左区固定按最大 `210 pt` 内容宽度布局，右区固定按最大 `138 pt`
状态宽度布局，状态文字在该区域内右对齐并贴齐 `20 pt` 右内边距；状态、任务
内容或语言切换不再改变可见岛体几何。两行文字栈高 `40 pt`，上下各保留
`14 pt`，实际可见岛体固定为
`402 × 68 pt`。完成辉光使用独立 `30 pt` 透明效果预留，因此 AppKit 面板窗口
为 `462 × 128 pt`；扩大的部分透明、忽略点击，不改变岛体位置或视觉尺寸。
展开态连续圆角保持 `20 pt`；进度条紧凑态可见高度仍为 `52 pt`，面板窗口
高度为 `112 pt`，宽度以九种状态的简中/
英文文案中最宽者为基准并保留原左右空白总量的 `60%`；单行状态文字占满固定内容表面并与
灵动岛中心重合。AI 球两种动画的既有文字和尺寸几何保持
不变。普通状态的烟雾前沿继续保留向右延伸的低密度多尺度扩散尾迹。

普通运行态不再为文字增加阴影，而是让透明度渐变跟随当前烟雾前沿动态
拉伸：烟雾可见范围的最左端为 `50%`，沿当前前沿方向逐步增强，前沿及其
右侧低密度扩散尾迹保持 `100%`，不能把渐变固定在整个岛体宽度上。完成瞬态
绕过这层局部渐变，仍可完整铺满全岛，再按既有时序整体变暗和淡出。左侧对话标题和
操作详情继续使用白色 `72%` 的次级文字色；标题前的状态圆点保留黑色
`82%`、`0.5 pt` 描边。右侧当前状态保持白色，AI 球样式不受影响。

可读性统一通过烟雾色彩亮度控制，而不再为 `compactingContext` 分叉透明度
规则。压缩态由近白银色改为低亮度、轻微偏冷的灰白梯度；`working` 使用
提高明度与青色占比、同时混入灰度控制饱和度的亮青蓝梯度，避免深蓝沉闷，
也不恢复容易与白字竞争的高饱和荧光青。两种状态与其他普通状态共同使用随当前可见烟雾宽度拉伸的
`50% → 100%` 透明度曲线，状态切换不再改变透明度结构。完成瞬态仍绕过该
曲线。

烟雾运动与进度前沿分离：前沿位置继续只表达近似进度，不加入装饰性往返。
`compactingContext` 不使用聚拢或向内密度波；它保留普通扩散方向，但明显降低
整体场速度、末端扩散强度、尾迹基础速度和速度变化幅度。其他活动状态使用
双尺度动态扩散：宽尺度控制扩散轮廓与长度，细尺度控制边缘碎裂；尾迹时钟
使用更高基础速度，并叠加正弦速度变化，形成持续加速和减速，而不是匀速平移。
断连与不可用仍冻结场时间，完成态仍由独立铺满、变暗、淡出序列接管。

进入 `completed` 时触发一次完成瞬态：进度确认到 `100%`，烟雾约在
`0.42 s` 内从当前前沿快速
扩展并覆盖整个灵动岛，随后在约 `0.8 s` 内完成整体变暗，再用约 `0.36 s`
完全淡出。烟雾退场后露出既有原生灵动岛材质背景，岛体四周亮起均匀的
绿色弥散辉光，以约 `1.8 s` 周期持续呼吸。辉光图层位于原生岛体图层下方，
只负责模糊扩散；另以位于岛体上方的独立 `1 pt`、sRGB `#00FF11`
纯净绿色描边提供稳定边缘，
描边颜色与透明度不参与呼吸变化。两层都不会改变岛内材质、文字位置、可见
岛体尺寸或状态生命周期。

## 已确认问题

产品所有者截图确认上一版全表面绿色烟雾把灵动岛变成了大块实色背景，缺少
最初烟雾前沿的层次，也不符合“在左侧小范围跳动”的预期。产品所有者在
首轮修正预览后曾将范围从 20%–30% 收窄为 15%–22%；产品所有者随后确认
整体前沿必须由近似进度唯一决定并从 0% 开始。15%–22% 装饰回退已经废止，
不得再作为无计划或新任务的初始位置。

产品所有者随后确认，单步任务通常不会调用 `update_plan`，导致旧实现把它
长期当成无进度并停在左缘，只有多步任务才明显触发进度效果。修正后的无计划
通道从 0% 连续推进，普通思考约以 `8 s` 时间常数渐近，工具执行、等待确认、
上下文整理分别保证至少 `28% / 40% / 46%`，运行中封顶 `50%`，避免把
无计划单任务误表达为接近完成；计划一旦
出现即接管，但不能让已经显示的前沿倒退。

产品所有者在准备 0.4.1 定版时确认，多步骤任务仍然走入单步骤估算。根因是
Codex 桌面端把 `update_plan` 包装在顶层 `exec` 自由文本调用中，而旧 Hook
只识别顶层工具名恰好等于 `update_plan` 的字典输入，因此计划计数从未进入
QuotaView。修正后的 Hook 同时保留直接路径，并只在 `exec`、
`functions.exec` 或 `functions__exec` 中以有界词法扫描识别精确的
`tools.update_plan(...)`；字符串、注释、动态参数和损坏结构不猜测，多个
调用使用最后一个有效计划。解析完成后立即丢弃原始脚本、步骤和说明，仅传
三类状态计数。

产品所有者在紧凑态截图中确认，完成后的绿色高光仍把岛体内部染成绿色。
根因不是烟雾未淡出，而是高光层使用完整圆角矩形作为零偏移阴影源，并位于
原生表面上方；紧凑态高度降低后，阴影半径覆盖了几乎整个内部。修正后高光
先改为岛体后方的透明描边环，并通过偶奇遮罩隔离内部。产品所有者进一步
明确“底部”指图层层级而非空间位置：最终实现以岛体内部缩进的完整圆角路径
作为四周阴影源，辉光图层位于原生岛体下方，偶奇遮罩隐藏阴影源和全部岛内
像素，只保留向四周扩散的柔光。呼吸只改变外部辉光的强度与扩散半径，岛内
继续显示原生材质背景。

产品所有者首次验收四周辉光时确认画面仍只显示黑色阴影。根因是绿色辉光
作为岛体容器的前一个同级视图，被后绘制的黑色基础阴影覆盖。最终层级改为
同一岛体容器内的“黑色基础阴影 → 绿色呼吸辉光 → 原生岛体表面”；绿色层
位于基础阴影上方、岛体表面下方。后续验收发现偶奇遮罩的外矩形仍会切断
模糊辉光；由于上层岛体表面本身已经覆盖内部光源，最终移除该遮罩，由真实
图层遮挡保证岛内不受影响，使外部辉光自然衰减而不再显露矩形边界。

产品所有者第二次验收确认四周辉光已经出现，但最低呼吸相位过暗。最终将
阴影源缩进从 `2.5 pt` 收紧到 `1.25 pt`，同时提高绿色饱和度、静态亮度和
呼吸最低亮度。最新截图进一步确认 `10 pt` 窗口预留仍会在最大呼吸相位裁切
模糊，且描边与呼吸阴影共用图层会让边缘不够纯净。最终将进度条样式的透明
效果预留扩大到 `30 pt`，可见岛体位置和尺寸保持不变；绿色高光拆为稳定
`1 pt` 描边与下层呼吸辉光，只有下层改变模糊半径和强度。

产品所有者还确认偶发出现 Codex 已无任务但灵动岛仍停留在“正在检查工具
执行结果”。诊断记录显示应用重启期间 Activity Hook 会退回文件队列；旧实现
既可能缺少最终 `Stop`，也可能在 `Stop` 之后才收到同一轮迟到的
`PostToolUse`。修正后，同一轮已经收到 `Stop` 时忽略迟到的结束型事件；若
完全缺少 `Stop`，`PostToolUse`、`PostCompact` 或 `SubagentStop` 后连续
`20 s` 无新事件则直接隐藏，不伪造完成态。重启重放时按事件原始时间扣除
等待，已经超时的旧事件不会重新展开；新一轮 `UserPromptSubmit` 会正常取消
收敛并开始显示。

## 状态映射

| 状态 | 主色 | 前沿运动 |
|---|---|---|
| `disconnectedCodex` | 暗蓝灰 | 无有效进度时前沿为 0%，场静止 |
| `standby` | 深蓝 | 前沿跟随近似百分比，场缓慢运动 |
| `thinking` | 紫蓝 | 前沿跟随近似百分比，双尺度尾迹变速向外扩散 |
| `working` | 低饱和亮青蓝 | 前沿跟随近似百分比，扩散长度、边缘与速度快速变化 |
| `compactingContext` | 冷灰白 | 前沿保持当前近似百分比，末端扩散更弱且低速运动 |
| `awaitingConfirmation` | 橙黄 | 前沿保持当前近似百分比，尾迹以较缓节奏变速扩散 |
| `completed` | 绿色 | 快速铺满、变暗、淡出，随后显示原生背景与四周绿色呼吸辉光 |
| `error` | 红色 | 保持可用近似百分比并提高扰动；无进度时为 0% |
| `unavailable` | 中性灰 | 无有效进度时前沿为 0%，场静止 |

## 渲染与边界

1. Metal fragment shader 覆盖完整圆角内容表面，但右侧只渲染深色背景；
2. 恢复原始四层 value-noise fBm、domain warp 和烟雾密度幂次结构，并在
   普通前沿右侧叠加低密度、多尺度、随扰动变化的扩散尾迹；
3. 活跃任务先在 `1%` 等待 `4 s`；有效计划进度下，`frontPosition` 平滑
   接入 `0%...95%` 的近似进度；窗口结束仍无计划时从 `1%` 启动本地生命周期
   估算，普通思考按时间渐进，工作、确认和整理状态提供
   `28% / 40% / 46%` 的单调最低位置，最高为 `50%`；迟到计划仍可接管；
4. 状态 Profile 提供颜色、场速度、运动频率、扰动和脉冲，不再改变进度
   前沿的横向位置；
5. 进度条展开态左区以逻辑表面左侧 `20 pt` 为起点，上方显示对话标题、
   下方显示带流光的当前操作详情；右区以 `20 pt` 右内边距右对齐显示当前状态，
   两区间距固定 `14 pt` 并整体垂直居中；展开与紧凑态分别以全部简中/英文
   内容的最大需求固定宽度，紧凑态单行文字使用完整表面宽度居中；其他视觉
   模式复用原有光球文字几何；
6. Reduce Motion 下，有计划时烟雾前沿静态落在当前近似进度；无计划时不做
   时间动画，思考、工作、确认和整理使用 `12% / 28% / 40% / 46%` 静态阶段位置；已完成状态直接隐藏烟雾并显示原生背景与静态四周绿色辉光；隐藏时停止
   绘制；Metal 失败回退到现有粒子球；
7. 不恢复从 0% 填满到 100% 再清空的循环；结构化计划优先，无计划回退只
   使用本地经过时间和已存在的视觉状态，不读取任务文字、模型输出、Token
   数量、工具参数或结果；
8. 不绘制额外亮核、圆形光球或独立进度条控件。
9. 完成瞬态只在进入 `completed` 时触发一次；重复设置同一状态不重播，离开
   已完成状态立即清除烟雾淡出和四周绿色辉光，快速反转不能残留满岛、变暗或
   高光参数；烟雾透明退场后暂停 Metal 连续绘制。
10. 完成高光使用岛体内部缩进的完整圆角路径作为四周阴影源，辉光图层放在
    原生岛体后方；由上层岛体表面覆盖内部阴影源，不再使用会裁出矩形边界的
    偶奇遮罩；进度条样式
    固定使用原始 100% 展开尺寸，紧凑态也不受 AI 球尺寸档位影响，均不得用
    完整圆角矩形阴影或上层遮色把岛内染绿。
11. 进度条展开态使用 `20 pt` 连续圆角；展开与紧凑转换期间在 `20 pt` 和
    紧凑态半高圆角之间平滑插值，AI 球的既有圆角不变。
12. 进度条样式的标题、状态、说明和紧凑态文字不使用投影或文字底板；普通
    运行态烟雾叠层以当前前沿为动态归一化范围，最左端为 `50%`，前沿及扩散
    尾迹为 `100%`，既降低左侧动态图层对文字的干扰，又确保尾端突出；完成
    瞬态绕过局部渐变，AI 球样式保持不变。
13. 进度条展开态左侧的对话标题与操作详情使用同一白色 `72%` 次级色；
    标题状态圆点增加黑色 `82%`、`0.5 pt` 描边；右侧当前状态保持白色。
14. 上下文压缩态不得使用单独透明度曲线；它与执行态及其他普通状态统一
    使用左端 `50%` 到前沿和扩散尾迹 `100%` 的动态透明度曲线。压缩态通过
    低亮度冷灰白配色、执行态通过低饱和亮青蓝配色平衡明度和白色文字可读性。
15. 运动语义不得改变进度前沿：压缩态取消聚拢，降低整体场速度、末端扩散
    强度、尾迹速度及其变化幅度；其他非静止状态使用宽/细双尺度动态尾迹，
    提高基础扩散速度并周期性加减速；断连、不可用、完成态继续遵守各自既有
    静止或完成序列。

## Requirement

| ID | 要求 |
|---|---|
