# 灵动岛特效长时间稳定性修复

Spec ID：`QV-FIX-EFFECT-LONGEVITY-020`

状态：`Accepted / Verifying`，2026-09-12；用户已授权修复全部现用特效。

## 要求与边界

- LONG-01：量子噪点长时间运行仍保持独立颗粒、随机分布、既有尺寸和覆盖范围。
- LONG-02：量子噪点、状态烟雾、晶钻前沿、液态涌浪的时钟与坐标保持有限精度，
  时钟回绕不能造成瞬间切换；切状态不重置运动，减少动态效果和暂停行为保持原样。
- LONG-03：用生产 Metal 函数验证长时间噪声分布、颗粒覆盖及回绕前后连续性；
  保留旧实现失败证据，完成回归及 Universal 无签名构建。

不修改业务数据、进度含义、完成语义、窗口布局、账户、代理或小组件。

## 原因与验证入口

生产噪声函数对不断增大的坐标进行浮点乘法后取小数，导致随机值量化。
隔离 GPU 测试中，模拟工作 1 小时只剩 94 个量化桶，2 小时 55 个，更久降至 29 个。
共用噪声影响其他效果；原 fieldTime 在 4096 处直接回零，pulse 的相位回绕周期
也未包含实际 1.9 倍频率。量子位移、相位和 effectTime 原为无界 Float 累加。
证据：`dist/verification/long-running-effects/baseline.log`；不写入真实运行数据。

## 实现

- 共用噪声改为整数混合哈希，避免大坐标浮点乘法取小数造成随机值退化。
  随机排列会改变，颗粒间距、半径、抖动幅度和占有率维持原值。
- 量子位移用 Double 累积，按 4096 个颗粒单元回绕；GPU 同步回绕颗粒身份，
  不将任意像素取模造成接缝。切状态继续沿用相位和位移。
- 共用时钟保持在 256 单位以内，最后 8 单位平滑混合下一段采样，避免不同
  频率的波形直接归零；通常只采样一次，交叠窗口内多一次采样。
- 呼吸相位在乘入真实频率后按完整周期回绕；effectTime 同样有界。
- 新噪声使中性颗粒亮度略升，按既有亮度回归上限将中性曝光从 1.55 校准至
  1.51，色相和彩色曝光保持原值；没有放宽旧测试标准。

## 验证结果

- 5 项新增回归：GPU 噪声 0～24 小时分布、24 小时量子运动、30 天时钟响应、
  四种生产效果回绕前后连续性、颗粒位移回绕身份连续性。
- 修复后 GPU 每个小时样本均覆盖 256 个量化桶；旧版同一测试失败证据已保留。
- 完整 Swift 回归 226 项，224 通过、2 项既有 opt-in 跳过、0 失败。
  原有颗粒亮度、空隙、全高覆盖、状态切换和减少动态效果回归继续通过。
- Universal Release 无签名构建通过；App、Widget、Core、Hook 含 arm64/x86_64；
  版本仍为源码基线 0.4.8 / internal 26，资源检查通过。永久开发台重新构建通过。
- `git diff --check`、文档链接及生产临时注入检查通过。证据目录中的
  `swift-tests.log`、`universal-release.log`、`artifact-check.json` 和 `console-build.log`
  分别记录测试、构建、产物和开发台结果。
