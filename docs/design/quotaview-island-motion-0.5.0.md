- 身份：`0.5.0 Build 3 / internal 29`，当前公开稳定版；已确认正常动效基线仍为 Build 2，回滚版本为 0.4.8 Build 4。
- 岛体底色：运行与完成、展开与缩略均使用不透明纯黑；内部效果淡出后保持黑色，不显露 HUD 磨砂材质。保留既有描边和外侧辉光。
- 呼出：从系统状态栏下缘的小胶囊向下冒出，0.82 秒非线性长大、宽高错峰果冻回弹；新任务展开到最大态。
- 缩略 → 展开：复用呼出的 0.82 秒非线性弹簧和宽高错峰果冻回弹；保持表面顶边位置与透明度。
- 展开 → 缩略：0.28 秒，短暂加速后逐渐减速，起止速度为零；单调到达目标，无弹性或尺寸越界。
- 整体回弹：主要展开时更新逻辑几何，各维度首次到达目标后保持布局稳定；末端通过共同容器的
  frame / bounds 变换，让外壳、文字、图标与特效一起弹性缩放，文字不重新排版或反复截断。
- 淡入辅助内容切换：旧文字在动作起步的 0.08 秒内淡出，布局在不可见时切换；呼出 / 展开
  延迟 0.12 秒后用 0.14 秒淡入，让内容参与可见回弹。缩略文字在外壳到位后淡入，隐藏不再补显文字。
  快速切换从当前视觉几何、逻辑几何和透明度接续；Reduce Motion 直接到位。
- 隐藏：先到缩略态，再收起淡出，每段 0.28 秒；已是缩略态时省略第一段。
  呼出途中被隐藏打断时，中间态的宽高分别不超过当前尺寸，避免尚未长大的维度反而增大。
- 位置保持原生产契约：屏幕可用区域居中，表面顶边距离可用区域顶边 16 pt。
- 真实任务的识别、完成回执、自动缩略 / 隐藏计时保持既有 Store 规则。
  数据刷新不重启动画；新任务打断隐藏时从当前画面接续；停止或关闭功能立即隐藏。
- Reduce Motion 直接到位；悬停透明命中按真实可见表面计算；隐藏后停止动画与特效工作。
- `CodexActivityIslandMotion.swift` 为应用与开发台共用时间线，四种效果保留 LONG-020 修复。
