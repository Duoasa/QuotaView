# QuotaView 0.4.5 灵动岛悬停透明

> Spec ID：`QV-PRODUCT-ACTIVITY-ISLAND-HOVER-TRANSPARENCY-012`
>
> 状态：`Accepted / Publishing`
>
> 目标版本：`0.4.5 Build 1`（Sparkle 内部 Build `17`）

## 1. 决策

鼠标进入灵动岛实体区域时，整个灵动岛进入 80% 透明态，也就是窗口保留
20% 可见度；鼠标移出后恢复完全不透明。透明变化只影响视觉，不改变任务
状态、进度、几何、生命周期或完成反馈。

## 2. Requirement

| ID | Requirement |
|---|---|
| `ISLAND-HOVER-01` | 悬停命中灵动岛实体区域时，整个窗口 alpha 切换到 `0.20`；移出时恢复 `1.00` |
| `ISLAND-HOVER-02` | 透明态覆盖进度效果、文字、完成光晕、描边与阴影，不改变内部渲染状态 |
| `ISLAND-HOVER-03` | 窗口继续设置 `ignoresMouseEvents = true`，透明功能不得拦截点击、拖动或滚动，后方内容保持可操作 |
| `ISLAND-HOVER-04` | 命中范围只使用灵动岛实体表面，不包含为阴影和完成光晕预留的透明外边距 |
| `ISLAND-HOVER-05` | 默认使用 `0.14 s` ease-out 过渡；开启 Reduce Motion 时即时切换，不播放透明动画 |
| `ISLAND-HOVER-06` | 隐藏灵动岛时清除悬停状态并恢复 `1.00`，避免下次显示继承旧透明度 |
| `ISLAND-HOVER-07` | 不新增设置项或持久化键；不改变 0.4.5 的进度条单一样式和量子噪点默认值 |

## 3. 实现边界

- 使用本地和全局只读鼠标移动监视器判断光标位置，事件必须原样继续传递。
- 以窗口屏幕坐标减去现有 effect inset 得到实体表面命中矩形。
- 窗口首次显示、尺寸变化或跨屏重定位后重新计算悬停状态，支持光标静止时
  灵动岛移动到光标下方的情况。
- 监视器随控制器生命周期移除，不保留后台轮询。

## 4. 验证

1. 单元测试固定 `1.00` / `0.20` alpha、`0.14 s` 时长和实体区域几何。
2. 代码检查确认窗口仍点击穿透，local monitor 返回原事件，global monitor
   只读取鼠标位置。
3. 运行 `swift test`、Universal Release 无签名构建及资源、架构、签名检查。
4. 启动 0.4.5 开发包，只做运行冒烟；透明度观感、命中范围和后方内容操作
   由产品所有者验收。
