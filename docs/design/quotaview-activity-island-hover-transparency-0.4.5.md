# QuotaView 0.4.5 灵动岛悬停透明

> Spec ID：`QV-PRODUCT-ACTIVITY-ISLAND-HOVER-TRANSPARENCY-012`
>
> 状态：`Accepted / Verifying`（原固定透明度已发布，本次可配置扩展未发布）
>
> 起源版本：`0.4.5 Build 1`（Sparkle 内部 Build `17`）；扩展初始开发基于 `0.5.1 Build 9`，提交 PR 时整合到上游 `0.5.1 Build 13` / `cef1c23`，不修改上游版本配置。

## 1. 决策

2026-09-30 用户授权扩展现有悬停设置，并提供正常与悬停截图说明遮挡问题。
根据随后对滑块方向的反馈，界面以“悬停可见度”表达整数 `0–100%`：`0%`
完全透明、`100%` 完全不透明，越向右越明显。默认 `20%`（等价于 `80%` 透明度），
与 Git 基线 `hoveredAlpha = 0.20` 一致。提供单项恢复默认；鼠标移出后恢复完全
不透明。兼容已保存的旧透明度，不将重装/打开新包视为重置。透明变化只影响视觉，不改变
任务状态、进度、几何、生命周期或完成反馈。复用现有设置页与偏好存储，
不增加架构模块、真实账户操作、发布或模拟入口。

## 2. Requirement

| ID | Requirement |
|---|---|
| `ISLAND-HOVER-01` | 悬停命中灵动岛实体区域时，整个窗口 alpha 为 `界面可见度百分比 / 100`，等价于 `(100 - 存储透明度百分比) / 100`；默认 `0.20`，移出恢复 `1.00` |
| `ISLAND-HOVER-02` | 透明态覆盖进度效果、文字、完成光晕、描边与阴影，不改变内部渲染状态 |
| `ISLAND-HOVER-03` | 窗口继续设置 `ignoresMouseEvents = true`，透明功能不得拦截点击、拖动或滚动，后方内容保持可操作 |
| `ISLAND-HOVER-04` | 命中范围只使用灵动岛实体表面，不包含为阴影和完成光晕预留的透明外边距 |
| `ISLAND-HOVER-05` | 默认使用 `0.14 s` ease-out 过渡；开启 Reduce Motion 时即时切换，不播放透明动画 |
| `ISLAND-HOVER-06` | 隐藏灵动岛时清除悬停状态并恢复 `1.00`，避免下次显示继承旧透明度 |
| `ISLAND-HOVER-07` | 在“进度条效果”预览下方、同一卡片内提供“悬停可见度 / Hover Visibility”原生无刻度滑块；不放在顶部开关/屏幕定位卡片，也不混入完成后的收起计时。整数 `0–100%`、默认 `20%`，0 为全透明、100 为完全不透明；继续使用 `preferences.codexActivity.hoverTransparency` 存储 `100 - 可见度`，读取和写入越界值均钳制，合法 0 不作为缺省值；不改变效果默认值。本条替代原版“不新增设置项或持久化键”的限制 |
| `ISLAND-HOVER-08` | 设置变更即时应用于任务岛与连接引导岛；光标静止于实体内时也更新，目标不变时不重启动画；全透明不等同于隐藏，移出仍恢复。设置文案、Tooltip、辅助功能标签由 `AppCopy` 提供中英文 |
| `ISLAND-HOVER-09` | 说明面向最终用户，使用“降低鼠标悬停时的可见度，便于查看下方内容。”及对应英文，不再常驻解释0/100%端点、默认值或开发背景；默认20%保留在单项恢复默认按钮的悬浮提示中；只重置悬停可见度，不改变其他偏好。已有透明度值换算显示，不静默覆盖（如旧 35% 透明度映射为 65% 可见度）；缺省使用20%可见度，重开或重装不强制重置 |

## 3. 实现边界

- 使用本地和全局只读鼠标移动监视器判断光标位置，事件必须原样继续传递。
- 命中矩形沿用 0.5.0 动效基线：将真实 `surface.bounds` 转换到屏幕坐标并与窗口边界求交，包含弹性缩放，不以透明 canvas 或窗口 alpha 判断命中。
- 窗口首次显示、尺寸变化或跨屏重定位后重新计算悬停状态，支持光标静止时
  灵动岛移动到光标下方的情况。
- 监视器随控制器生命周期移除，不保留后台轮询。
