## TOKEN-ACTIVITY-00. 范围

本功能在状态栏菜单的用量数据列表下方显示按日期聚合的 Token 活动图表，
帮助用户在有限宽度内快速比较近期和长期活动。图表只消费 Codex App Server
返回的官方每日用量桶，不引入 SQLite、本地长期历史推断或账户写操作。

非目标：

- 不显示模型、Agent、费用或 Prompt 明细；
- 不存储或补造 App Server 未提供的历史；
- 不用颜色表达账户风险或服务健康状态；
- 不改变 WidgetKit 快照、Codex 灵动岛或额度重置 Demo 的业务语义；
- 不包含 `0.3.2 Preview 1` 的多任务灵动岛生产实现。

## TOKEN-ACTIVITY-01. 数据与时间范围

1. `account/usage/read` 的 `dailyUsageBuckets` 投影为 UTC 自然日和 Token 数量；
2. 同一天出现多个桶时合并求和，最终按日期升序显示；
3. 用户可以选择最近一周、最近一个月、最近三个月和全部可用历史；
4. 一周包含今天及之前六天，一个月包含今天及之前三十天；三个月从当前
   UTC 日期向前推三个月后再加一天；总计从最早有效桶到今天；
5. 没有历史桶时，总计使用一个月的日期范围维持稳定可理解的空状态；
6. 默认范围为最近一个月，用户选择持久化在
   `preferences.panel.tokenActivityRange`。

## TOKEN-ACTIVITY-02. 网格几何

1. 每行固定 `16` 个 `12 × 12 pt` 连续圆角方格，方格间距 `3 pt`；
2. 每个范围的总格数必须为 `16` 的整数倍，形成完整 `16 × N` 网格；
3. 真实日期按时间顺序填充并右下对齐；不足一整行的格子只允许出现在
   左上角，使用占位格补齐；
4. 占位格使用 `3.5%` 透明度填充和 `0.75 pt`、`[2, 2]` 虚线描边，不能
   冒充真实日期或零用量；
5. 图表宽度固定为 `237 pt`，行数和高度随范围与实际总计跨度变化。

## TOKEN-ACTIVITY-03. 单色用量阶梯

数据格按当前范围内最大 Token 数量归一为五级，零值或缺失为第一级，
非零值按 `<25%`、`<50%`、`<75%` 和 `≥75%` 进入后四级。

- 深色外观：不透明白阶 `16% / 32% / 48% / 64% / 80%`；
- 浅色外观：不透明灰阶 `80% / 64% / 48% / 32% / 16%`；
- 数据格不得使用彩色或额外透明度；
- 占位格继续使用低透明度，且必须与真实最低用量格可区分。

颜色只表达相对 Token 量级。日期、紧凑数值和辅助功能文本提供非颜色信息。

## TOKEN-ACTIVITY-04. Hover 与辅助功能

1. 指针在真实日期格停留 `0.5 s` 后显示自定义 Tooltip；
2. Tooltip 只显示本地化日期和紧凑 Token 数量：小于 `1,000` 的非零值为
   `<1K`，其余使用至多一位小数的 `K / M / B`；不得显示长整数字符串；
3. 指针离开、切换范围、图表消失或视图模型变化时立即取消待显示任务并
   清除 Tooltip；
4. 占位格不可 Hover，并从辅助功能树中隐藏；
5. 每个真实日期格提供本地化日期 `accessibilityLabel` 和用量
   `accessibilityValue`；图表容器提供明确的 Token 活动统计标签。

## TOKEN-ACTIVITY-05. 面板尺寸与切换

1. 菜单宽度保持 `274 pt`，图表完整显示，不裁切或压缩方格；
2. 周期变化导致行数变化时，面板顶部和菜单栏锚点保持固定，只移动下边缘；
3. 向更高图表切换时先准备目标内容高度，再提交范围状态，避免新网格先在
   旧窗口中布局；
4. 收缩和扩展统一使用 `0.14 s` ease-out 尺寸过渡；同一目标不得重复启动；
5. SwiftUI 内容变化只合并到下一次主循环布局，不增加多帧固定延迟；
6. Reduce Motion 开启时取消尺寸动画，直接设置顶部固定的目标 Frame。

## TOKEN-ACTIVITY-06. 设置、请求与降级

1. 设置窗口的面板内容分组提供“Token 活动图表”原生 Switch；
2. 开关默认开启，持久化为 `preferences.panel.showTokenActivity`；
3. 只有每日 Token、累计 Token 和 Token 活动图表全部关闭时，才允许停止
   请求可选 usage 数据；
4. 图表关闭后不保留高度；重新开启时恢复用户上次选择的范围；
5. usage 请求失败不得污染主额度数据；无日桶日期仍以最低级真实格显示，
   Tooltip 表达“统计不可用”。

## TOKEN-ACTIVITY-07. 验收与发布门禁

自动化必须覆盖：

- 四个范围的 UTC 日期边界、完整 16 列网格和左上占位数量；
- 默认设置、设置持久化和 usage Demand；
- Hover `0.5 s` 延迟、取消与紧凑数字格式；
- 面板顶部固定几何、目标高度准备和 Reduce Motion 降级；
- 深浅外观数据格均为不透明五级单色，占位格保留透明度。

## TOKEN-ACTIVITY-08. 变更控制

- 修改列数、格子尺寸、颜色阶梯、Hover 延迟、范围语义或顶部锚定行为，
  必须更新本规格并使用新的 Build Number；
- 每次更新或构建都必须使用新的可识别版本号；`0.3.3 Build 3` 之后的任何
  代码变化不得继续复用 Build 3；
- 0.3.2 Preview 的多任务模块只可作为独立参考，不能随本图表功能静默进入
  稳定版。
