# QuotaView Token 活动规格

> 文档编号：`QV-PRODUCT-TOKEN-ACTIVITY-001`
>
> 规格状态：`Accepted`
>
> 交付状态：`Released`（0.3.3 首发，0.3.4 Build 3 更新范围语义）

本图表只消费 Codex App Server 返回的官方每日用量桶，不建立本地长期历史、
模型/Prompt 明细或账户写操作。

## 数据与范围

- `dailyUsageBuckets` 按 UTC 自然日投影；同日有效桶合并求和，未来、负数和
  范围外桶忽略；缺失日期保持“统计不可用”，不能伪造为零；
- 可选范围为最近一周、一个月、三个月和半年；默认一个月，旧 `total`
  偏好迁移为半年；
- 周/月/三个月使用连续日期范围。半年从最近六个月内最早有效桶开始；若
  没有有效桶，则使用一个月的空状态；不得补造六个月之前的历史；
- “最近一天 Tokens”、30 日汇总、成本和本图表必须消费同一组保留真实
  UTC 日期的桶。最近桶不在今天时不得改写为“今日”或复制到今天。

## 网格与色阶

- 每行固定 16 个 `12 × 12 pt` 连续圆角格，间距 `3 pt`，图表宽 `237 pt`；
- 真实日期升序并右下对齐，总格数补齐到 16 的整数倍；补齐格只出现在左上，
  使用 `3.5%` 填充和 `0.75 pt`、`[2,2]` 虚线描边，不响应 Hover 且从辅助
  功能树隐藏；
- 数据按当前范围最大值归一为五级：零/缺失、`<25%`、`<50%`、`<75%`、
  `≥75%`。深色白阶为 `16/32/48/64/80%`，浅色灰阶反向为
  `80/64/48/32/16%`；不用彩色表达风险或服务健康。

## 交互、布局与设置

- 指针在真实日期格停留 `0.5 s` 后显示本地化日期和至多一位小数的
  `K/M/B` Token 值；离开、切换、隐藏或数据变化立即取消；
- 菜单宽度保持 `274 pt`。范围变化只移动面板下边缘，顶部/菜单栏锚点不动；
  目标高度先准备后切换，使用 `0.14 s` ease-out，Reduce Motion 直接设置；
- 显示开关 `preferences.panel.showTokenActivity` 默认开启；范围保存在
  `preferences.panel.tokenActivityRange`。关闭后不保留高度；
- 最近一天、30 日、累计、Token 活动或成本任一开启时，usage Demand 保持
  开启；全部关闭后才停止可选 usage 请求；usage 失败不得污染主额度。

## Requirement

| ID | 要求 |
|---|---|
| `TOKEN-ACTIVITY-01` | UTC 日桶、同日合并、真实日期和四个当前范围 |
| `TOKEN-ACTIVITY-02` | 完整 16 列、右下对齐和不可交互的左上占位 |
| `TOKEN-ACTIVITY-03` | 五级不透明单色及非颜色辅助信息 |
| `TOKEN-ACTIVITY-04` | 0.5 秒 Tooltip、取消语义和 VoiceOver |
| `TOKEN-ACTIVITY-05` | 顶部固定收展、Reduce Motion 和动态高度 |
| `TOKEN-ACTIVITY-06` | 设置持久化、usage Demand 与失败隔离 |
