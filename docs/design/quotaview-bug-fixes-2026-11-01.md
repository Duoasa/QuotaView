## 本轮修复

| 原编号 | 最终行为 |
|---|---|
| H1、M6 | Kimi 使用 TOML 专用转义，支持普通绝对路径、单引号、Unicode、反斜杠和控制字符；检查 hooks 赋值、普通表及隐式父表冲突。允许已有 `[[hooks]]`，无法可靠判断的转义键保守拒绝改写，保留用户配置。 |
| M1 | 单条记录、缓存字段及聚合都检查 Int64 溢出；非法记录产生 invalidUsage，扫描结果 complete=false；聚合溢出跳过该项并使当天成本未知。总数及加法返回可空结果，运行时不发布溢出值，不伪装为零或饱和值。 |
| M2、M5 | 共享 socket 非阻塞连接、写入、握手读取共用单调时钟的总期限；取消会传入打开任务并关闭 fd。连接前后核对目录/socket 属主和权限，并核对连接对端 UID；不声称可以区分同 UID 的其他进程。 |
| M3 | 初始化成功但迅速断开的连接也执行 250 ms 起、最高 5 s 的重连退避；停止可取消等待。 |
| M7 | 只保留审批需要的 item 字段，排除输出；上下文每项 32 KiB、总计 2 MiB、最多 200 项。换轮、trace 清理、原生内容替换和线程关闭时回收。缺失/超限的文件变更上下文及已知被淘汰的工具上下文降为只读，不批准截断的内容。 |
| L2、L3 | stderr 超长行丢弃至换行后继续消费；stdout 保持超限断连。JSON-RPC 先区分服务器请求，返回不支持方法，不能用同号 ID 取走客户端待处理请求。 |
| L10 | 两种 app-server 连接的请求计时任务在响应、取消、断开时取消。 |
| L11、L21 | Claude 通用工具审批显示完整参数 JSON；超过 64 KiB 的通用输入交回原客户端。AskUserQuestion 的重复/空题目拒绝映射，避免返回按题目为键的 answers 时覆盖。 |
| L12、L23 | Native 安装器以最终权限创建独占临时文件，写完同步再 rename，检查失败；安装锁最多等待 2 秒且响应取消。 |
| L13、L22 | Claude 自有 Hook 识别支持安装器生成的 shell 单引号转义，同时拒绝命令拼接/替换；不能备份的 statusLine 类型在安装前拒绝覆盖。 |
| L16 | 两种 Hook 监听首包使用 1 秒总接收期限，滴流不能持续延长；保留正常短延迟及总大小限制。 |
| L17 | 原 statusLine 命令使用独立进程组；stdin、stdout、子进程退出共用 5 秒期限，输出最多 64 KiB；超限/超时清理进程组。关闭 stdout 后继续运行也不能无限等待。 |
| L20、L29 | Native Hook 核对 ACK eventID；标题请求被 rebound 取消时同步清除任务句柄和 session 标记，使后续恢复可重新请求。 |

L26 的已处理部分：只在会话准入后保留 name/title/model/effort 等有界展示字段，
不缓存整个 thread 历史；线程关闭同时清理 metadata、priorTurnKeys、desktop scope、
pending local content 和 item context。正在保留的任务之旧轮次集合仍维持防迟到回放语义。
