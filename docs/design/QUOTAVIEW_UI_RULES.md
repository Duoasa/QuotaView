- 用量来源标签在 Codex / Claude Code 名称前显示对应 14 × 14 pt 无底框标志（Codex 白色、Claude 陶土橙），图文与标签间距均为 6 pt。高度 28 pt、12 pt Medium 字号及左右 8 pt 内距与顶部用量按钮共用 `IslandChromeMetrics`；选中背景和点击区域使用 Capsule，左缘对齐卡片、名称不截断。图标对辅助功能隐藏，按钮保留来源名和选中状态。Claude 使用官网原始矢量标志，任务卡、子任务、标签与重置卡共用原始轮廓及缓存资源，重置卡保留奶油白配色，不使用系统星号占位；来源见[图标记录](quotaview-provider-icons.md)。
- 基础数据固定显示，仅成本与 Token 活动可隐藏；关闭收起空槽。未知数据不绘为零，订阅和重置次数来自真实快照。

- 成本与 Token 活动提示框位于本卡片及相邻卡片描边之上；本卡片描边放在内容背景层，悬停卡片在兄弟卡片层级提升，避免描边穿过提示内容。
- hover/选择切换复用统计模型，不因鼠标移动重算历史成本或整年活动网格；缓存随实际活动数据、累计值和 UTC 日期更新，不能掩盖数据刷新或把未知值变为零。

- 重置页 Asta Sans：标题/次数 15 pt Semibold；额度标签 11 pt Regular、值 11 pt Medium；须知/空态标题 11 pt Semibold，正文 11 pt/3 pt 行距；按钮 13 pt Semibold；反馈/待刷新 10.5 pt。

- 玻璃启停保持卡片内容身份与转场宿主；飞行等待窗口/锚点有效后启动，按动画完成回调交接静态卡片，不从点击时固定截断。保留停播、快速返回与卸载清理，不增加逐帧 SwiftUI 刷新。

## 自带字体可靠性

- Asta Sans 保留既有字号/字重，通过应用内字体数据构建并校验字体对象；SwiftUI 与 AppKit 共用加载结果，避免仅凭名称选中其他字体。
- 缺失、不可读取、解码失败或缺少数字/百分号/金额符号/未知值占位符字形时，回退对应字号/字重的系统字体。不得因字体资源异常中断界面或用问号替换真实数据。
- 字体加载与注册异常记录字体名及错误信息，不记录账户或用量内容。正常字体只加载一次，不在渲染更新时反复读盘。

  `9 pt semibold`，每行 `11 pt`，条宽 `24 pt`、高 `4 pt`；百分比按 `100%`
  预留固定宽度。图标与双行内容共用 AppKit 模板图片，随系统状态栏着色。
- Build 2 起开启倒计时时，各窗口的时间放在对应百分比之后；仅倒计时模式
  保留周期标签。悬停始终提供逐窗口重置时间，未知为 —，到期为待刷新。
- Build 6 单周期使用原生文字百分比与可选倒计时，`14 pt Regular`，基线下移 `1.5 pt`（Build 9）；不显示
  周期标签或进度条，周期信息保留在悬停提示中。设置预览同字号。
- 设置预览共用生产模板图片；缺失数据为 `—%`，不能绘制为已知 0%。
- 至少保留图标、剩余额度或重置倒计时中的一项，不能让应用入口消失。

## 文案、辅助功能与实现

- 可见业务文案、Tooltip、辅助标签和时间单位经 `AppCopy` 支持中英文，不硬编码额度、计划、次数或语言。
- 设置下方使用系统语义色；黑色主岛的白灰层级遵守自身令牌。状态不得只靠颜色表达，数据连接圆点仅代表最近获取是否有效。
- 保留 Default/Hover/Pressed/Disabled、help、accessibilityLabel、必要 hint、键盘与焦点；contentShape 覆盖完整视觉热区。
- 小字号用于紧凑辅助信息，关键数据保持明确层级；17 pt 以下普通文字以 4.5:1、18 pt 或粗体以 3:1 为对比目标。实际体验由用户验收。
- Reduce Motion、隐藏、离屏、禁用、卸载应停止持续效果，保留静态反馈。复用既有 Layout/Palette/Typography/ButtonStyle，不增加逐帧 SwiftUI 状态或窗口 resize。
- 不以虚构业务状态维持画面，不加入自动代答或真实额度重置。构建、缓存测量与截图都不能代替用户体验结论。

实时设置预览的渲染预算、暂停及回退规则见[实时预览规格](../specs/settings-live-effect-preview.md)。
