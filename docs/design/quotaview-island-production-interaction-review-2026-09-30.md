# 刘海灵动岛 · 生产交互与显示规则

Spec ID：`QV-PRODUCT-ACTIVITY-ISLAND-PRODUCTION-003` · `Accepted / Verifying` · 整理：2026-10-08。
文件名保留以兼容既有链接；本页已接替最初审核稿。当前交付见 [Handoff](../../HANDOFF.md)，精确视觉参数见[界面规范](QUOTAVIEW_UI_RULES.md)。旧提案、决策编号及阶段流水见[完整快照](../archive/maintenance-20261008/README.md)。

## 范围与状态

- 当前主入口是本机多任务灵动岛；真实任务、公开内容、用量与有能力的请求在同一外壳内展示。
- `Prototypes/MultitaskIslandConsole/Frozen/2026-09-30-3s-sync-noise65` 保持固定 Demo；生产已沿独立源码继续开发，不能把 Demo 的纯模拟限制套到生产，也不能用生产修改覆盖固定快照。
- 已有实现与用户体验验收分别记录。远程/云端应答、可靠原生前台聊天选择、原生异步问题组关闭均不由本规格宣称已支持。
- 真实额度重置保持演示；退出 QuotaView 不结束 Codex 或 Claude 中的任务。

## 身份、来源与任务保留（T01–T07）

| 对象 | 归属与不变量 |
|---|---|
| 会话 | provider/来源命名空间 + 真实会话身份；改标题、模型或目录不新建卡片 |
| 执行轮次 | 会话 + turn；工具、内容和终态必须属于该轮 |
| 请求 | 来源、owner、epoch、原始 typed request ID、会话/轮次；显示标题不提供身份 |
| 草稿 | 请求身份与内容修订；不能绑定“当前选中的卡片”而串题 |
| 子 agent | 权威父子关系，父卡片下堆叠；自己的模型、状态与时长，不继承父应答权 |
| 记忆/内部任务 | 原生来源与精确执行证据分类；记忆用独立底栏球，内部任务不混进用户统计 |

来源及生命周期详细契约由[信息契约](../specs/codex-island-information-contract.md)维护。不能凭标题、目录、时间接近或模型缺失猜身份。
真实最终事件优先于本地估计，旧轮次不能覆盖新轮次；Socket 接收时间不与持久记录发生时间直接比较判新旧。
列表保持稳定顺序，新任务追加。完成卡片不随下一批自动清理，用户手动按轮次归档；归档仅隐藏 Island 展示，不归档/删除原生聊天。新轮次可重新出现，重启恢复遵守来源准入，不承诺持久完整历史列表。

## 状态与公开内容（S01–S04、F01–F10、E01–E05）

| 情况 | 显示规则 |
|---|---|
| 活跃轮次 | 有明确工具时显示具体操作，其余使用真实公开进展；不生成“思考故事” |
| 上下文压缩 | 只有真实压缩事件进入；不伪装任务完成 |
| 阻塞请求 | 待确认优先显示，仍保留并行工具事实 |
| 异步问题 | 问题提示与真实运行状态可并存，不推导执行已阻塞 |
| 工具失败/拒绝 | 仅对应操作失败/拒绝，不直接结束整轮任务 |
| 真实终态 | completed/interrupted/failed 分别显示，旧请求失效 |
| 连接中断 | 保留最后可信状态并标过期；无事件不等于空闲/完成 |

- 只展示公开助手消息、工具活动与公开输出，排除私有推理、加密内容、agent 间私信。
- 标题、模型、思考等级、来源、时长及 Token 不为填满布局而删减或伪造；缺失值使用占位符。
- 时长和 Token 的周期明确，不能把会话累计当成本轮 Token，不能把工具次数当进度。
- 完成详情呈现原始最终回答，支持 Markdown 层级与用户点击链接；摘要去除行内标记，原文不改写或翻译。
- 原文/历史披露使用有界缓存和实际测量；状态刷新不重置正在阅读的位置，也不把最终文本重复追加。

## 外壳、选择与滚动（I01–I05、L01–L02、U01–U04）

2026-10-11 15:29 修订：普通详情按内容在 60–128 pt 内自动贴合，替代早期二档跳变，不使用手动收窄按钮；正文 12 pt，标题栏和内容间距见[界面规范](QUOTAVIEW_UI_RULES.md#灵动岛与卡片)。超过两格上限时内部滚动。

- 主岛随应用运行可达；真实摄像头安全区留空，多屏/全屏/休眠遵循当前窗口生命周期。
- 手动选择、固定页面和已有草稿优先；不猜 Codex 当前前台会话。
- 自动弹出默认开启，停留 1–10 秒、默认 3 秒；新任务与完成按该时长展开，普通刷新不续时。
- 新真实请求可进入详情；待确认保持展开但允许手动收起、保留草稿。同请求刷新不重新弹出，新请求仍按偏好处理。关闭自动弹出不停止观察。
- 列表和请求正文使用连续原生滚动，保留惯性及轨道；不恢复吸附、滚轮拦截、逐帧窗口 resize 或文字布局。
- 详情跟随任务卡片，按内容占一格 60 pt 或两格 128 pt；完成结果与进展统一采用任务卡的连续曲率轮廓与材质。标题/关闭入口固定，长正文在内部滚动，玻璃表面不进入正文裁切层；任务卡、详情与内部视口固定宽度，覆盖式滚动条不撑宽卡片。几何变更同步保存/恢复外层锚点和可见集合，用户滚动优先；数据刷新不把列表跳回顶部。
- 详情压缩留白和段落间距，隐藏重复来源、进展标签和成功退出码，保留正文、失败信息、工具原文与较早记录入口；正文使用与“查看原文”一致的次要灰色，区别于明亮标题。子 Agent 合入父卡第三行，共享完整玻璃轮廓、不加分割线；进度特效保持原主内容区域，不覆盖第三行。横向溢出不增加行数，长模型信息仍可使用原有补充行。
- 只为可见卡片及有界邻近缓存挂载渲染器；离屏、隐藏、暂停、减少动态与卸载停止持续渲染。

## 卡片与公共入口

- 选中主卡及审批头卡移除 AI 球和空图标列，只显示进度/状态特效；未选中保留 28 pt AI 球。完成态不重复叠加球和辉光。
- 主卡、子 agent 背板、审批头卡共用不透明 1 pt 描边：普通 `#181818`，hover/选中 `#202020`；全组同步 hover。
- 连接且无用户任务显示“就绪 / Ready”；收起待机左侧仅真实剩余百分比或“—”，展开栏保留完整用量。
- 完成后收起球位显示剩余比例 3 秒；完成数大于零才每 3 秒轮播会话/完成数，初次历史同步不触发。
- 记忆球 18 pt、固定“记忆整理 / Memory consolidation”标签与压缩上下文效果；Tooltip 保留真实状态。
- 任务、用量、重置和请求页面共用刷新/设置工具区。设置采用顶部导航与固定黑色示意区、下方滚动菜单；完整参数集中在[界面规范](QUOTAVIEW_UI_RULES.md#设置窗口)。

## 类型化请求（A00–A11）

十类页面共享外壳与请求生命周期，具体内容来自真实协议，不能只换标题或依据任务名猜类型。

| 类型 | 必需内容与能力边界 |
|---|---|
| A01 命令 | 原始命令、目录与影响；范围仅来自原请求可用决定/规则 |
| A02 终端输入 | 原目标与原始输入；未证明协议能力时回原生处理 |
| A03 文件修改 | 路径、差异与影响；不把路径摘要作为回传值 |
| A04 网络 | 目标/域名、理由与允许的规则范围 |
| A05 文件/网络权限 | 逐项呈现请求范围；持久授权不默认勾选 |
| A06 第三方工具 | 原工具/连接器上下文与影响；授权和字段表单分别处理 |
| A07 问题 | 原问题、选项、自行输入能力；完整有效草稿才可确认 |
| A08 结构化表单 | 按受支持 schema 渲染和校验；无字段纯授权使用“批准” |
| A09 外部授权 | 原服务与下一步；在原生/外部页面处理，不猜成功 |
| A10 原生验证/未知类型 | 只读说明与原生处理；缺详情不误判成 macOS 系统权限 |
| A11 其他事件 | 不强套为可响应请求，不从观察内容创造批准能力 |

请求正文视口最多 440 pt 并受当前屏幕可用高度限制，底部操作固定。长命令默认最多 8 行/2048 字符，可查看或复制完整原文；选项/规则最多两行，路径中部缩略。测量和显示使用同一限制，回传始终保留原始内容。
只布局真实可用操作：一个满宽、两个等宽、三个 3:3:4；42 pt 高、8 pt 间距、10 pt 圆角。持续、会话或规则范围都须由用户明确选择，不作为后续请求默认值。

## 请求、草稿与应答（R01–R10、K01–K05）

1. 先校验来源、当前 owner/epoch/轮次、完整 typed ID 及响应能力；观察来源和未知协议保持只读。
2. 选择选项、编辑、自行输入只改当前请求草稿，不能发送。返回、切换和收起保留有效草稿；失效、换轮或不兼容修订清理对应部分。
3. 用户显式确认只发送一次；发送中禁用重复提交。迟到回调不能覆盖新请求或新连接状态。
4. ACK 只表示已发送。精确权威请求移除/回答证明才结算；操作结果与整轮完成继续由真实事件证明。
5. 写入后超时/断线显示结果未知，不自动重试、不在重连后补发。仅明确未发送且仍有能力时允许重试。
6. 并行请求独立保留；处理一项不清整组，不提供“全部允许”。关闭详情或退出应用不发送默认允许/拒绝。
7. 同步跳过走原协议；异步跳过/提醒退场仅作用 Island，本地隐藏不代表 Codex 原生问题框关闭。

Codex 精确应答及原生关闭缺口见[Desktop 同步规格](../specs/codex-desktop-confirmation-sync.md)。Claude 独立 helper、终端回退与审批开关见[Claude 规格](../specs/claude-code-support.md)，不能互用路由。

## 用量与重置

真实可用基础数据固定显示，成本估算与 Token 活动可单独关闭且收起空槽。未知值不伪造零，价格缺失不生成通用估算。
账户分隔线下方整区（含留白）是重置入口；hover 只显示底部渐变高光，不增加手形或描边。
用量/重置采用同一 3D 卡片过渡节奏，卡面高光 2 秒；次数为零、未知、待刷新分别显示。所有重置动作保持演示，不调用真实 consume。

## 资源、隐私与验收（P01–P02、B01–B03）

- 原始 ID 用于可靠路由，日志只保留必要的哈希/计数/固定状态；审批答案、秘密字段、私信和完整原生状态不落诊断日志。
- 复用原渲染器、时钟和缓存；状态不变不重复发布，禁用功能停止对应后台任务。
- 功能验证按受影响链路做必要冒烟/基准；真实显示、点击、辅助功能、长时间及多屏体验由用户验收。
- 尚未证明的能力明确回退；Spec Accepted 和已有构建/发布都不表示全部矩阵通过。当前未完成项只在 [Handoff](../../HANDOFF.md#未完成项) 与 [Design QA](../../design-qa.md) 维护。
