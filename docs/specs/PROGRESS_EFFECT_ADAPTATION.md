# QuotaView 进度条效果适配协议

用途：批量把新的视觉参考适配为进度条灵动岛的内部进度效果。参考只提供
视觉语言，不覆盖现有灵动岛产品规则。

## 1. 修改边界

只允许修改进度条样式的渲染层：

- 进度主体形态及其 shader / renderer；
- 进度位置的视觉映射；
- 状态颜色、速度、扰动、密度、透明度和局部运动；
- 到达 100% 后、主效果淡出前的结束动作。

必须复用，不得重复设计：

- 顶层 `.progressBar` 样式、窗口和原生岛体背景；
- 展开态左侧标题/操作、右侧状态及紧凑态居中排版；
- 展开可见尺寸 `402 × 68 pt`、圆角 `20 pt`、四周 `30 pt` 效果预留；
- 按简中/英文最大内容固定的展开与紧凑尺寸；
- 近似进度算法、任务生命周期、VoiceOver 和 Reduce Motion；
- 完成后的原生背景、`1 pt` 纯绿色描边和四周呼吸辉光；
- AI 球样式及其 100% / 85% / 75% 展开尺寸。

不得新增第二个灵动岛窗口、改变文字位置或让 AI 球读取新效果参数。

## 2. 进度语义

新效果可以用位置、长度、覆盖率、密度、聚拢度、激活比例或有序程度表达
进度，但必须遵守同一语义：

- 无活动任务：`0%`；
- 任务开始：在 `1%` 等待 `4 s` 识别结构化计划；
- 有计划：`(completed + 0.1 × inProgress) / total`，运行中封顶 `95%`；
- 无计划：识别期结束后接入单步骤估算，封顶 `50%`；
- 迟到计划可以接管，但显示不得倒退；
- 只有真实完成事件进入 `100%`；新任务必须清空旧进度。

呼吸、波动、旋转或跳动只能发生在当前进度附近，不能改变用户感知到的
单调进度。不得使用从 0% 到 100% 循环播放的装饰动画。

## 3. 状态映射

保持同一进度位置，仅改变效果 Profile：

| 状态 | 运动语义 |
|---|---|
| 思考中 | 中等活跃，具有探索性变化 |
| 执行中 | 更明确、更活跃，允许周期性变速 |
| 压缩上下文 | 降低速度、扰动和末端扩散 |
| 等待确认 | 保持位置，以克制脉冲提示用户 |
| 失败 | 保持可用进度，使用红色及不稳定语义 |
| 未连接 / 不可用 | 降低亮度并停止主要运动 |
| 待机 | 不显示虚假进度，只允许低强度环境运动 |
| 已完成 | 推进到 100%，完成本效果结束动作后淡出 |

状态 Profile 不得自行修改近似百分比。

## 4. 可读性

- 效果始终位于文字下层，不给文字新增阴影、发光或背景板；
- 优先降低文字区域的亮度、密度、饱和度或不透明度；
- 高亮和主要细节优先集中在当前进度末端；
- 透明效果默认随可见进度范围从左端 `50%` 增强到末端 `100%`；不适用
  透明度的效果必须提供等价的亮度或遮罩衰减；
- 不得以过曝白色、高 Bloom 或高饱和填充覆盖标题和操作详情；
- 不改变现有文字颜色、状态圆点描边和右侧状态可读性规则。

## 5. 完成与降级

新效果只负责“如何到达 100%”：

1. 推进至完整状态；
2. 播放一次自身的结束动作；
3. 变暗或降低能量并淡出；
4. 交还现有原生背景、绿色描边和四周呼吸辉光。

重复完成事件不得重播；离开完成态必须立即清除残留。辉光不得染绿岛体
内部或被窗口裁出矩形边界。

同时必须满足：

- Reduce Motion 使用当前进度的静态表现；
- Metal 不可用时沿现有路径安全回退；
- 窗口隐藏或主效果完全淡出后停止持续渲染；
- 状态快速切换不残留上一状态的颜色、材质或动画。

## 6. 单个效果登记模板

```text
效果名称 / ID：
参考：
核心视觉语言：
进度载体（位置/长度/密度/其他）：
必须保留的辨识特征：
各状态的 Profile 差异：
文字区域的降噪方案：
到达 100% 的结束动作：
新增渲染参数：
Reduce Motion / Metal 回退：
新增测试：
```

## 7. 验收门禁

- 0%、1%识别期、计划进度、单步骤 50%、运行中 95%和完成 100%正确；
- 进度单调，迟到计划接管不倒退；
- 简中/英文及全部状态切换时岛体尺寸不跳动；
- 展开与紧凑态文字不被遮挡，右侧状态保持右对齐；
- 完成后恢复原生背景，并正确显示既有绿色描边与呼吸辉光；
- Reduce Motion、Metal 回退、隐藏暂停和快速状态切换无残留；
- 不影响 AI 球、设置中的 AI 球尺寸档位或现有任务生命周期。

一句话原则：只替换进度条内部的视觉表达，复用灵动岛本体、进度语义、
信息结构、生命周期和完成反馈。
