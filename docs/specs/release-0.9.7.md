# QuotaView 0.9.7 macOS 发布

用户已授权 macOS 0.9.7 Build 1（内部 238）发布并纳入 Sparkle 自动更新。发布 tag 为 `v0.9.7-build.1`，资产为 `QuotaView-v0.9.7-build.1.zip`。上一稳定版及回滚基线为 [0.9.3 Build 1](https://github.com/Duoasa/QuotaView/releases/tag/v0.9.3-build.1)，其公开 ZIP 已回下载核对 SHA-256。

本版包含任务输出速率与显示选项、完成动效、Antigravity 接入、六款桌面客户端的会话跳转，以及设置和用量页更新。中英 README 同步新版功能和客户端支持范围。

Apple 公证已接受。正式包完成 Staple、Gatekeeper、隔离启动与公开回下载验证。PR 与发布 main CI 已通过。签名 appcast 已部署并通过线上验签，完整资产、回滚及 CI 记录见[版本历史](../../VERSION_HISTORY.md#当前最新版本)。
