# QuotaView 0.9.7 macOS 发布

用户已授权 macOS 0.9.7 Build 1（内部 238）发布并纳入 Sparkle 自动更新。预期 tag 为 `v0.9.7-build.1`，资产为 `QuotaView-v0.9.7-build.1.zip`。当前稳定及回滚基线为 [0.9.3 Build 1](../../VERSION_HISTORY.md#当前最新版本)，其公开 ZIP 已回下载核对 SHA-256。

本版包含任务输出速率与显示选项、完成动效、Antigravity 接入、六款桌面客户端的会话跳转，以及设置和用量页更新。中英 README 同步新版功能和客户端支持范围。

用户已同意新的 Apple 开发者协议，公证服务访问已恢复。签名资产须经公证、Staple、Gatekeeper、公开回下载核验后部署签名 feed。
