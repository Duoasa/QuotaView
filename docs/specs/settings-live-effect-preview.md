# 设置实时特效预览

Spec ID：`QV-SETTINGS-LIVE-PREVIEW-001` · 状态：`Accepted / Verifying`

## 授权与范围

2026-10-09 用户要求三个动效和设置可视化均使用动态实时预览，并优化性能。
该要求替代此前静态特效图片限制。保留预览比例、宽度滑块联动、示例内容、
隐私、中英文、圆角和三个选项的 56 pt 视口。

## 实现契约

- 上方示例卡实时播放所选效果；状态烟雾、量子噪点、液态涌浪三个选项均实时
  播放各自效果，不依赖 hover 或选中。固定工作状态和 60% 示例进度，不循环
  模拟真实任务完成，不读取真实任务、账户或响应能力。
- 复用 `ActivityStateSmokeMetalView` 及按 GPU/像素格式缓存的 shader 管线。
  SwiftUI 仅负责布局和偏好变化；无 TimelineView、逐帧 SwiftUI 状态、
  新增轮询或任务计时器。最多四个可见小视口渲染。
- 每个预览上限 24 fps、1 像素/pt。drawable 随视口尺寸变化时更新；生产任务
  渲染器的帧率/分辨率保持原设置。文字与图标仍原生渲染。
- 窗口遮挡/最小化、应用隐藏、祖先隐藏、滚动裁切区域及卸载事件控制播放。
  滚出视口或窗口不可见暂停；只在实际播放边界更新 renderer，不逐帧发布
  可见状态。不为可见性增加周期轮询，销毁时清理观察者。
- Reduce Motion 保留静态效果；Metal 初始化失败使用已打包效果图。
  背景效果不拦截选项按钮或其他交互。
