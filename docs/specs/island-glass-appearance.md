# 灵动岛玻璃外观与统一胶囊

Spec ID：`QV-ISLAND-GLASS-APPEARANCE-001` · 状态：`Accepted / Verifying` · 2026-10-15。

## 目标与范围

用户要求参考 macOS 外观设置提供浅色、深色、自动三种可视化选择，且仅在液态玻璃模式显示。随后明确问题位于岛下方的纯玻璃按钮与文字，并要求悬浮用量胶囊共用该选择、只保留显示开关，以及重排灵动岛设置。

本规格只适配下部纯玻璃区域和胶囊。收起态、顶部黑色渐变、任务/用量/审批卡片和设置窗口本身继续使用现有深色方案；不更改账户、数据、任务行为或系统外观设置。

## 要求

- **R1 外观与保存**：新增 `island.glassAppearance = light / dark / automatic`。首次、缺失或非法值回退 dark，保持已有主岛默认。经典纯色隐藏选择且保留值；切回玻璃恢复选择。独立的 `island.usageCapsuleTone` 不再读取或展示，旧存储不清除，避免误将历史胶囊浅色扩展到整个底栏。
- **R2 自动跟随**：一个共享对象以公开 AppKit KVO 观察 `NSApplication.effectiveAppearance`，自动采用系统实际浅/深状态，无自建日夜时段、轮询或系统偏好写入。固定浅/深不随系统改变。
- **R3 作用域**：任务、用量、审批和重置共用底栏按所选 colorScheme 渲染明确黑/白文字及刷新/设置按钮，避免非激活窗口语义前景令图标变灰，底部玻璃背景匹配环境；黑色渐变参数与深色卡片不变。浅色按钮使用轻白 tint 0.22 和深色文字，深色沿用轻白 tint 0.04 与浅色文字。系统玻璃继续负责光学高光，不引入私有 API、截图、祖先遮罩或定时器。
- **R4 胶囊统一**：悬浮胶囊与底栏使用同一解析结果。与岛体下部共用 `IslandNativeBackdropMaterial` 的无染色 clear 玻璃，取消胶囊独立 black 0.55 / white 0.22 底色。深色白字、浅色黑字，倒计时和分隔线跟随前景色。真实数据、显示开关、隐私规则与固定尺寸逻辑不变。经典纯色或减少透明度时采用深色实体回退，保留选择供玻璃恢复使用。
- **R5 设置与预览**：顺序为“外观与布局”（材质、仅玻璃显示的外观三选项/玻璃程度、展开宽度）、“显示内容”（胶囊显示、隐私）、“任务特效”、“自动展开”。三张缩略图采用系统同类桌面/窗口意象，Auto 左浅右深，选中外框使用系统强调色；所有标签由 AppCopy 提供中文和 English，支持键盘与辅助功能选中状态。上方现有岛预览同步底栏、玻璃背景和胶囊，不注入真实任务。

## 依据

- [Apple：在 Mac 上使用浅色或深色外观](https://support.apple.com/en-ie/guide/mac-help/mchl52e1c2d2/27/mac/27)：Light、Dark、Auto 的选择语义；本应用 Auto 跟随系统已解析外观。
- [Apple：ColorScheme](https://developer.apple.com/documentation/SwiftUI/ColorScheme)：使用 SwiftUI 外观环境；非激活面板文字按该环境明确选择黑/白对比色。
- 用户 2026-10-15 提供的系统设置三选项截图、底栏截图；缩略图为本地原生形状与现有壁纸资产组合，不复制系统截图为交互控件。
