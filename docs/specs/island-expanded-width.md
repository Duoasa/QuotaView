# 灵动岛展开宽度与窄屏图表

Spec ID：`QV-ISLAND-EXPANDED-WIDTH-001` · 状态：`Accepted / Verifying`

## 授权与目标

2026-10-09 用户要求将现有展开宽度作为上限，为带刘海 MacBook 选择合适下限，
允许手动调节；仅覆盖任务列表和用量页。成本柱图与 Token 方格图在空间不足时
横向滚动，默认定位最近数据。用户所说“横向进度条”按保留图表、提供横向滚动条
实施，已告知该解释；未收到替换图表为进度条的进一步要求。

## 宽度契约

- 设置入口：灵动岛 → 显示 → 展开宽度。普通范围 `560–680 pt`，默认 `680 pt`，
  持久化键 `island.expandedWidth`；旧安装没有此键时保留原最大宽度。
- 最小值为 `max(560, cameraWidth + 360)`，并受原最大宽度和屏幕安全边界限制。
  `360 pt` 包含刘海两侧各 `144 pt` 可用栏宽、左右共 `56 pt` 内距和 `16 pt`
  摄像头间隔。真实刘海宽度来自系统安全区域，不按机型名称或像素分辨率硬编码。
- 最大值沿用原规则：`min(max(680, compactWidth + 64), screenWidth - 48)`。
  正常范围为 680 pt；既有特殊屏幕约束继续生效。非法/非有限偏好归一化。
- 任务列表及其内联详情、用量页即时响应宽度。收起态、审批页和额度重置页沿用
  各自原尺寸，不因滑块变窄。外层原生窗口保持最大画布，仅调整岛体和内容。

## 设置预览联动

- 用户后续明确要求设置可视化中的灵动岛也跟随设置按比例变化。预览宽度为
  `510 × 实际生效宽度 / 原最大宽度`，普通范围对应 `420–510 pt`；使用同一
  刘海安全范围，拖动立即更新，并在辅助功能说明中提供实际 pt 值。
- 仅岛体和内部卡片/工具栏横向重排；壁纸、整体顶部居中、150.4 pt 内容高度、
  字号和图标尺寸不变。底部轮廓与阴影使用原图端部保护，仅拉伸中段。
- 保留完整中英文示例与隐私模式；用户后续要求实时动效，效果层按[实时预览规格](settings-live-effect-preview.md)播放，不挂载真实任务或任务计时器。

## 用量适配

- 双额度窗口继续横向等宽排列，账户列在 `168–204 pt` 内响应可用宽度；额度
  标题/倒计时和值行不足时换行，保留实际值。数据缺失与隐私状态不伪造数据。
- 柱宽至少 `8 pt`，Token 方格边长至少 `10 pt`，间距 `3 pt`。Token 图保持 53 列，其最小内容宽
  `686 pt`；成本图保留原有 30 日柱图及两侧汇总。内容超出视口时提供原生横向
  滚动条和手势，月份标签随网格一起滚动。滚动条可见轨道 3 pt、滑块 4 pt，保留原生命中区域。
- 初次挂载、切换来源/活动模式、调整宽度或进入新日期时定位到最右的最近数据。
  普通数值刷新不强制复位用户正在查看的历史位置；无溢出时完整展示原图。
- Tooltip 通过可见元素的锚点定位在滚动视口之外，保持在图表及相邻卡片描边
  之上；完全离开视口的锚点不显示。调整宽度或卸载时清理 hover。
- 复用原有统计模型缓存，不增加轮询、逐帧状态或滚动坐标状态发布。
