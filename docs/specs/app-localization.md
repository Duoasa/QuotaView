## 目标

通用 → 语言提供简体中文、English、日本語、한국어、繁體中文、Español及跟随系统。切换后设置、任务状态、权限请求、重置页、用量与辅助功能文案使用同一语言；小组件接收相同语言标识。保留原有简体中文和英文偏好值。

## 不变量

- 语言只改变应用文案。账户名、路径、命令、任务原文、输出与回答不翻译。
- 动态值与翻译模板分离。占位符一次替换，不递归解析动态值中的 `{{n}}`。
- 繁体中文仅转换中文模板，并缓存转换结果；动态值随后原样插入。
- 新语言日语/韩语/西班牙语使用随包附带的 JSON 翻译，不访问网络服务。
- 系统语言按偏好顺序选择受支持语言；中文显式脚本优先，其次地区；无匹配回退英文。手动选择跨重启保留。
- 灵动岛模型、独立悬浮胶囊、SwiftUI 环境与权限内容测量使用实际语言，不能把语言压缩为中/英布尔值。历史布尔参数仅作旧调用方的兼容回退。
- 业务动作、重置保护与确认规则不变。验证不消耗真实重置卡。
- 正式安装、Release、appcast和Windows渠道保持原状。

## 实现

`AppLocalization.swift` 提供插值模板与共享资源读取，主程序和小组件使用同一份 `AppTranslations.json`。`AppCopy.text` 只接收模板类型；已经存储为字符串的固定效果标签通过独立的 `named` 入口，避免 Swift 默认字符串重载吞掉动态模板。

`AppPreferences.Language` 维护六种语言、原生名称与地区解析。运行链路传入实际语言，布局缓存包含语言，日期与金额采用所选 locale。`IslandDetailText` 区分应用双语模板和原始外部内容，流式变更后清除旧模板。
