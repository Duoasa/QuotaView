# 任务卡片显示设置

Spec ID `QV-PRODUCT-TASK-CARD-SETTINGS-001` · Accepted / Verifying · 2026-11-15

## 目标与范围

用户要求在设置中新增「卡片设置」，可独立选择速率、任务 Token、任务耗时、模型显示。沿用现有设置侧栏与原生开关，新增页面位于「灵动岛」之后。默认全部开启，已有用户外观保持；选择写入本机 UserDefaults，重启恢复。

## 行为与边界

- 四项独立开关即时生效，适用于所有来源的任务列表卡和待确认头卡；现有灵动岛外观预览同步选择。标题、任务详情与 Agent 标识保持。
- 关闭速率或任务 Token 后隐藏对应读数；只有两项均实际可见时保留中间细竖线，全关不保留空统计槽位。任务详情占用释放的空间，沿用裁切视口避让。
- 关闭耗时后隐藏时长及其与模型之间的分隔线；关闭模型后同时隐藏推理档位，并收起长模型额外行。子 Agent 行同步隐藏模型/耗时，空耗时不留下分隔符。辅助功能不朗读被隐藏字段。
- 开关控制展示，不清除累计用量、速率样本或任务计时；重新开启显示当前已有数据。既有速率快照、完成均值与新 turn 清零规则保持。
- 只有这四项选择落盘；不会把任务速率/完成均值变成跨重启持久化数据。来源缺少速率数据时，打开开关仍不伪造读数。

## 实现

`AppPreferences` 的四个布尔值默认 true，并分别保存至 `island.card.outputRate/tokens/duration/model`。`IslandTaskCardOptions` 从偏好生成展示投影，通过 `CodexActivityRuntime → IslandSession → IslandLiveStore.display` 传入任务卡；原任务记录保持。模型/耗时在 metadata 投影过滤，隐藏长模型后测高缓存自然使用空模型键，列表、详情头卡与特效内容高度一致。
