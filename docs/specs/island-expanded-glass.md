## 实现

- `IslandNotchSurface` 共用单个原生背景。macOS 26 使用无额外 tint 的 SwiftUI `.glassEffect(.clear)`、深色环境、24 pt 连续曲率轮廓（独立 `NSHostingView`）；macOS 14–15 使用 `NSVisualEffectView.hudWindow` / behindWindow。原生玻璃侧边与刘海下方主体侧边对齐，移除人工白色描边，由系统提供材质与高光；非激活外观已加入上方兼容修复，效果待用户确认，不能视为已匹配 Droppy。
- 刘海遮罩仅裁切黑色渐变层，玻璃宿主和玻璃模式下的内容祖先不再挂整岛 `CALayer.mask`，避免将原生 backdrop-sampling 材质压入离屏裁切。使用 0 / 55% / 67.5% / 80% / 100% 高度节点，黑色不透明度 100% / 100% / 45% / 0 / 0；下部不再叠加黑色。保持岛体尺寸和点击路由。
- 主任务卡与审批头卡使用 `RoundedRectangle(cornerRadius: 16, style: .continuous)` 和 `.regular.tint(.black.opacity(0.42))`，hover tint 为 0.32；移除实心黑底，文字与特效由卡片玻璃直接承载。完成态描边/外光路径同步连续曲率，原特效播放规则保留。子 Agent 按上方最新要求纳入父卡第三行，共用一层完整材质。
- 卡片右侧 Agent/归档共用按钮取消玻璃底框，保留 24 pt 命中区域、16 pt Agent 标志、原归档图标字号、hover/按下反馈和独立归档路由。其他工具栏/用量/重置按钮保持玻璃。
- 开启减少透明度时外层使用原有纯黑底层，卡片使用不透明深色回退；旧系统卡片用 regularMaterial 与稳定色底。收起时隐藏外层玻璃宿主、卡片材质切换 `.identity`；轮廓复用 Core Animation 过渡，没有增加计时器、屏幕捕获或私有滤镜。
- API 依据本机 macOS SDK 及 [Apple NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview)。截图内的建议不作为已验证的 Droppy 内部实现。
