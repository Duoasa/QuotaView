# 灵动岛显示位置

编号：QV-PRODUCT-ISLAND-DISPLAY-001 · 状态：Implemented / Awaiting user validation

通用设置提供焦点屏幕跟随开关，关闭时显示固定屏幕菜单，样式复用语言选择。默认关闭以保留主屏行为。活动应用前台普通窗口与屏幕交叠面积决定目标屏幕，无可用窗口时保留原屏；QuotaView 自身获得焦点时避免自追踪。复用每秒刷新，不新增定时器，单屏和固定模式不扫描窗口。

固定屏幕以显示器 UUID 保存，断开后回主屏而不覆盖保存值，重新接入恢复。显示器列表随系统通知刷新，离线选择显示未连接。所有位置共用岛体与用量胶囊的几何。无屏幕录制或辅助功能权限申请。

验收：开关切换、同应用跨屏切换窗口、固定屏幕重启持久化、拔插恢复与胶囊同步由用户实机验证。0.8.1 Build 5 / 内部 65 增量编译、运行身份及源码输入一致性检查通过；证据 `.build/screen-controls-20261012/`。
