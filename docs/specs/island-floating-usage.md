- 设置 → 灵动岛 → 显示 → 悬浮用量胶囊，默认开启，`island.floatingUsageEnabled` 持久化并立即生效。
- 按真实窗口时长 300 / 10080 分钟选择，不将 primary 固定理解为 5 小时；周数据缺失显示占位，不伪造额度。过期、加载中、不可用快照均显示未知值。

- 独立液态玻璃材质，不被经典岛体遮罩裁切；减少透明度用实体背景，旧系统用系统半透明材质。只读，不拦截鼠标或引发悬停展开。
- 复用同一窗口固定画布，几何跟随展开/收起/切页统一 0.38 秒插值；快速反向从当前插值续接。减少动态禁用过渡。所有页面最大高度预留 44 pt，避免底部裁切。
- 无新增 timer，数据更新即时发布，倒计时复用现有 session 时钟按分钟更新；关闭不显示，隐私模式隐藏，锁屏/灵动岛隐藏时随窗口隐藏。
