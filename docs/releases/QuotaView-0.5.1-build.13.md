# QuotaView 0.5.1 Build 13

Fixes missing quota readings when recent Codex desktop updates relocate the bundled CLI. QuotaView now finds the new executable location automatically while retaining support for older ChatGPT/Codex installations, standalone CLI installs, and custom executable paths.

This hotfix is based on the public 0.5.1 Build 9 release and leaves the interface and quota parsing unchanged.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.
