# QuotaView 0.4.3 Build 1 — Clearer Progress Feedback

[Download QuotaView-v0.4.3-build.1.zip](https://github.com/Duoasa/QuotaView/releases/download/v0.4.3-build.1/QuotaView-v0.4.3-build.1.zip)

QuotaView 0.4.3 polishes the Progress Bar introduced in 0.4.2.

## Highlights

- **Refined Quantum Noise:** State colors now transition without vertical
  motion, with denser twinkles, clearer context-compaction feedback, and a
  brighter controlled finish.
- **Clearer text hierarchy:** Opaque soft-gray task and status text improves
  readability while preserving the operation shimmer.
- **Unified completion glow:** The outline and breathing halo now share one
  consistent green.

The universal build supports Apple Silicon and Intel Macs running macOS 14 or
later. It is signed with the QuotaView Developer ID, notarized by Apple, and
stapled for offline Gatekeeper verification.

Signed installations on the Stable channel can receive this release through
QuotaView's in-app updater.
