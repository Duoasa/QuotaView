# QuotaView 验证规则

选择能证明本次结果的最小检查集；现有 CI、具体规格和正式发布要求的检查
仍需完成。通过后仅在新改动、失败或未覆盖风险出现时扩大或重复。

## 按变更选择

| 变更 | 必要检查 |
|---|---|
| 仅 Markdown 或 Skill 指令 | 受影响链接、职责/状态/授权一致性、`git diff --check`；Skill 格式与路由核验；不跑 Swift 或 Universal 构建 |
| 局部模型或状态修复 | 审查受影响状态和失败路径，相关回归测试；涉及共享契约或影响面不明时运行完整 `swift test` |
| UI、资源、显示逻辑或平台配置 | 相关状态/本地化/外观审查、受影响测试、Universal Xcode Release 无签名构建与受影响产物检查；公共状态变化运行完整测试 |
| 传输、并发、恢复、身份、迁移或多 Target 交互 | 边界和失败反例、集成检查、完整 `swift test`、受影响 Target 构建；必要时增加隔离运行验证 |
| 正式发布、更新或撤回 | [发布规则](RELEASE.md)、完整测试和下方产物/渠道检查 |

先确定测试是否访问真实账户、联网、修改安装或外部状态，不能把整个套件
笼统视为无副作用。已授权且使用临时夹具的本地检查可直接运行、修复本次
引入的失败并复验；真实账户、设备和渠道操作遵循实际授权。

## UI 与临时入口

- 检查变更影响的有效、缺失、刷新、禁用、取消和恢复状态；不为无关改动
  遍历所有界面。受影响的中文/English、深浅色和辅助功能语义保持一致。
- 视觉和交互记录“等待用户验收”，直到获得具体场景结论。正式发布前列明
  适用的深浅色、材质、语言、键盘、Escape、外部点击、Reduce Motion、
  Increase Contrast 和 VoiceOver 状态，不将单项确认扩大为全矩阵通过。
- 任务结束清除临时生产 UI QA；提交、推送或发布前移除虚拟注入，生产
  `Sources` 搜索 `DEBUG-ONLY-MOCK|DEBUG MOCK|仅用于调试` 应无匹配。
  永久 `Prototypes/IslandTextConsole` 和显式测试夹具保留。

## 发布与产物

核对实际产物的 Marketing Version、产品 Build、内部序号、Universal
`x86_64 arm64`、`AppIcon.icns`、`Assets.car` 和新增资源。版本来自
`Configs/App.xcconfig`、App/Widget 配置及包内 Info.plist。
正式发布还需签名、公证/Staple、动态库加载、解压启动、最终 SHA-256、
公开回下载及获准 appcast 的签名验证；编译通过不能替代这些证据。

## 文档与结果

- 执行 `git diff --check`，确认补丁范围。检查修改文件的链接与引用方，迁移
  段落保留历史证据并修正相对路径。
- Handoff 与版本历史保持双向入口。修改发布指针或声明时核对实际 Release/tag、
  资产和中英文下载入口；纯流程整理确认原有发布事实未被改写。
- 报告已验证、失败、未运行、阻塞和等待验收的实际项目；必要检查未完成时
  说明限制，无关项不逐条列 N/A。已有未提交源码未被本次改变时不重新测试它。
