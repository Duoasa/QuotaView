# Codex Activity Multi-Task Demo

这是一个与 QuotaView 生产工程、现有单任务 Metal Demo 完全隔离的原生
macOS 视觉原型，用于验证冻结的“固定单岛多任务”方案：

> SDD Spec ID：`QV-PRODUCT-ACTIVITY-ISLAND-MULTITASK-001`
>
> 规格状态：`Accepted`
>
> 交付状态：`Prototype`（当前正在 Demo 调试）
>
> 基线状态：产品所有者已于 `2026-08-02` 确认当前视觉与交互方向为后续
> 开发基线；用户于 `2026-08-04` 确认多任务适配为当前进行中工作。可以
> 继续修正 Demo 与规格的偏差，但改变冻结方向必须先确认，也不得迁移到
> QuotaView 生产代码。

唯一规格：
[QuotaView Codex 灵动岛多任务规格](../../docs/design/quotaview-codex-activity-island-multitask.md)。
当前阶段和授权边界以
[SDD 规格索引](../../docs/specs/README.md) 为准。

- 在控制窗口中设置 `1–4` 个纯模拟任务；
- 手动编辑每个任务名称；
- 为每个任务独立选择八种活动状态；
- 手动切换主任务，观察内容、任务指示与 Metal 球状态同步更新；
- 验证固定尺寸的单一主岛，不绘制或预留常驻背层卡片；
- 主岛内部使用右侧任务列表、当前任务标记与前后隐藏数量承载多任务概览；
- 切换时直接更新主任务内容与任务列表选中态，不对整张岛卡片做动画；
- 超过三项后任务列保持原始顺序并整体滚动，不交替替换单独一行；
- 切到最后一项时显示窗口从 `1–3` 滚到 `2–4`，最后一项位于底行；
- 最大态不显示左右竖向分割线，只使用内容尾部与任务列开头的留白分区；
- 紧凑态拆分为完整自适应状态、独立标题跑马灯和固定宽度的“共 N 项”；
- 紧凑态的“共 N 项”是详情入口，点击后切换到最大态；
- 在最大态、紧凑态与 Reduce Motion 降级之间切换；
- 灵动岛固定悬浮在控制面板上方，并随控制面板拖动。

原型不读取 Codex、不访问辅助功能、不使用 App Server 或 Hooks、不访问
网络，也不会修改 QuotaView 的设置、快照、源码、资源或构建目标。

## 运行

在项目根目录执行：

```bash
swift run --package-path Prototypes/CodexActivityMultiTaskDemo
```

运行独立原型测试：

```bash
swift test --package-path Prototypes/CodexActivityMultiTaskDemo
```

2026-08-04 当前自动化结果：`37` 项测试通过，`0` 失败。该结果只证明隔离
Prototype 的布局、状态和动效契约，不是生产 `Sources/`、Release 构建或
生产视觉验收证据。

## 视觉验证边界

- 单任务继续复用原 Demo 的动态尺寸和内容结构；
- 多任务最大态固定为 `496 × 152 pt`，使用右侧 `144 pt` 任务列表；
- 右侧增加的 `16 pt` 从左侧主内容区重新分配，最大态外轮廓不发生变化；
- 紧凑态高度固定为 `52 pt`，宽度由状态、标题和任务总数内容自适应；
- 多任务紧凑态右侧计数区支持鼠标点击与 VoiceOver Press，触发
  现有最大态展开动画，并同步设置面板的状态控件；
- 含投影预留的面板始终比可见胶囊增加 `20 pt` 宽高；
- 任务从两个增加到四个时，岛和外层窗口尺寸都保持不变；
- 不显示右侧小岛、背层卡片、堆叠边缘或其他仅用于装饰的任务容器；
- 任务切换不改变主岛卡片的位置、尺寸、透明度或透视角；
- 右侧三行任务视窗使用纵向滚轮动效：任务行强调保持
  `0.5 s`，整列位移与玻璃形变共用 `0.8 s`；
- 未选中任务使用 `5 × 5 pt` 状态圆点；选中任务在同一标记槽位改为
  `5 × 12 pt`、`2.5 pt` 圆角的选中线，不再保留独立的左侧提示线；
- 移除独立提示线后，任务名称起点从 `32 pt` 前移至 `24 pt`，释放的
  `8 pt` 全部用于任务文字，不改变 `144 pt` 任务列表和最大态外轮廓；
- 主任务切换时，当前 `5 × 12 pt` 选中线向右液化展开为
  `116 × 20 pt`、`6 pt` 圆角的原生玻璃矩形；左侧保留 `4 pt`，右边缘与
  最大态任务内容的 `24 pt` 安全边距对齐，刚好包裹任务选项；目标任务的
  状态圆点同步消失，玻璃在岛面之上、任务文字与圆点之下纵向滑到目标
  任务，随后再收缩为新的
  `5 × 12 pt` 选中线；
- 任务文字与圆点使用独立清晰前景层，不再作为 `NSGlassEffectView` 的
  背景采样内容，因此玻璃移动时文字不会被系统折射虚化；
- 右侧未选中任务仅在“思考中”或“工作中”时，任务名使用与主内容
  底部操作文字相同的 Codex 流光；主任务和其他状态保持静态；
- macOS 26 使用 Apple 原生 `NSGlassEffectView` 的 `clear` 风格，状态色
  tint 降至 `10%`，保持文字清晰可见；macOS 14–15 使用更清透的
  `underWindowBackground` 材质回退；
- 玻璃形变总时长为 `0.8 s`，中段与任务列滚动同步；Reduce Motion 下
  直接切换目标槽位的选中线，不显示液化和玻璃移动；
- 任务列顶部、底部和左侧保留 `12 pt` 安全边距，最大态右侧内容边距加倍
  为 `24 pt`；底部隐藏数量使用独立提示区；
- 三行任务统一为 `20 pt` 行高、`23 pt` 步进，标题、列表和提示之间均为
  `8 pt` 分区间距；
- 超过三项时顶部以“任务 + 任务计数器”的顺序居中显示，两者间距为
  `6 pt`，两者统一使用 `10.5 pt` 字号，底部同时显示“前 N / 后 N”；
- 一至三项时隐藏顶部和底部分页信息，并按实际行数将任务列表垂直居中；
- 状态区域按实际文字宽度计算，八种状态均完整显示且不保留最长状态空位；
- 标题视窗在 `44–128 pt` 内自适应，超出上限时循环滚动并使用左右渐隐；
- Reduce Motion 下标题停止滚动，并回退为静态尾部省略；
- Reduce Motion 下同时停止右侧后台任务名的流光；
- Metal 球保持同一个渲染实例，只同步切换状态；
- Reduce Motion 继续约束 Metal 球和任务选中指示器的局部动态。

这些数值与动效已冻结为后续开发基线；进入生产实现前仍需新的明确指令、
真实数据接入设计与生产级验证。
