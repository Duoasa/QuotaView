# 灵动岛内容开发台

这是用户明确要求长期保留的开发工具，不属于任务结束时应移除的临时 UI QA。
日常入口与重建步骤见 [README.md](README.md)。

- 保留源码、启动器、构建脚本和来源记录；生成目录 `.build/`、`dist/` 不进入 Git。
- 始终从当前工作区生产视图准备隔离副本，禁止冻结旧版渲染器或在生产 Sources 注入模拟状态。
- 模拟数据保留 DEBUG 标识。独立 Bundle ID，不启动生产 Store、活动桥、Hook、更新器或 Widget，不写生产用户数据。
- 构建身份来自生产 Info.plist；重新构建前先核对当前工作区，不沿用历史候选版本号。
- 保留手动状态、文字、额度和可停止的完整演示。用户负责视觉验收，自动化结果单独记录。
- 用户要求保留开发台不代表授权发布应用、更新 appcast 或替换已安装应用。
